# Protocolo ENTREGA_TURNO (Cierre de Jornada)
Ejecuta de inmediato:
1. **Revisión de Cierre**: Verificar estado final de tareas del día y logros.
2. **Registro de Log**: Registrar resumen de logros y actividades del día en wiki/log.md.
3. **Actualizar Dashboard**: Actualizar prioridades en wiki/life-dashboard.md.
4. **Cierre de Servicios**: Detener limpiamente cualquier instancia activa de scripts/telegram_bot.py.
5. **Persistencia Git**: Ejecutar git add ., git commit -m "chore(handover): cierre de turno [YYYY-MM-DD]", git push origin master.
6. **Informe de Despedida**: Presentar informe ejecutivo corto al Señor con el balance del día y pendientes para mañana.
