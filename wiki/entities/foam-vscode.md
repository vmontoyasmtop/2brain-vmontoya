# 🛠️ Foam (VS Code Extension)

**Foam** es un sistema de gestión del conocimiento personal (PKM) diseñado como una extensión para **Visual Studio Code**, inspirado en herramientas como Roam Research y Obsidian.

## 📌 Rol en 2brain con VS Code
- **Visualización de Grafo**: Ofrece un panel interactivo de vista de grafo (*Foam Graph*) directamente dentro de VS Code.
- **Navegación y Autocompletado de Wikilinks**: Permite usar enlaces de tipo `[[Página]]` con autocompletado en Markdown.
- **Sin depender de Obsidian**: Toda la edición, navegación, vista de grafo y mantenimiento se realiza 100% dentro de VS Code.
