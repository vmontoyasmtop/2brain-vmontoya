# 🛠️ Obsidian

**Obsidian** es una aplicación privada y flexible de toma de notas basada en archivos Markdown locales.

## 📌 Rol en el [[LLM Wiki Pattern]]
Karpathy describe a Obsidian como el **IDE** para la navegación del conocimiento, mientras que el agente LLM actúa como el programador y la wiki como el código fuente.

## 🔌 Plugins Destacados
- **Web Clipper**: Para guardar artículos web directamente en `raw/`.
- **Dataview**: Consulta y visualización dinámica a través del YAML frontmatter.
- **Marp**: Creación de presentaciones en diapositivas a partir del Markdown.
- **Graph View**: Visualización del mapa relacional de conocimiento.
